# Inventory Allocation System

## Purpose

This project models an inventory allocation system.

The system receives customer orders and allocates order lines
to appropriate inventory batches according to business rules.

## Problem

The system needs to determine:

- whether requested stock exists
- whether enough stock is available
- which batch should be allocated
- how allocations are persisted
- how errors are communicated to API clients

## Architecture

The application is divided into:

- Domain Model
- Service Layer
- Repository
- Unit of Work
- ORM / Data Mapping
- API / Entrypoint
